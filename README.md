# Nearby Mob HUD

Клиентский мод для **Minecraft 1.21.11 (Fabric)**. Находит отслеживаемых мобов
вокруг игрока и показывает в настраиваемой панели HUD по одной вращающейся 3D-модели
на каждый вид. Если рядом несколько мобов одного вида, рядом с моделью выводится их количество,
например `Cow ×3`. Для одного моба сохраняется подпись `Near: <имя моба>`.

Проект создан на основе шаблона `ComfortableStonecutter` и не изменяет его файлы.

## Возможности

- Сканирование мира раз в **10 клиентских тиков**.
- Поиск только выбранных типов мобов в настраиваемом радиусе вокруг игрока.
- **Одна модель на вид моба** и счётчик `×N` для каждого вида.
- Каждый вид выводится отдельной строкой: 3D-модель слева, название и количество справа.
- Чем больше видов рядом, тем меньше модели — строки автоматически делят высоту HUD.
- 3D-модель рисуется штатным рендерером игры через
  `GuiGraphics#submitEntityRenderState` — тем же путём, которым ванильный инвентарь
  рисует модель игрока. Внешние модели и ресурсы не используются.
- Плавное вращение моделей с настраиваемой скоростью.
- **Поисковый выбор мобов** с 3D-превью в мире и яйцами призыва на титульном экране.
- **Редактор HUD**: перетаскивание, изменение ширины/высоты за угол и масштабирование
  колесом мыши.
- **Своё меню настроек**: клавиша мода (по умолчанию `O`) настраивается в
  `Esc → Настройки → Управление → Назначение клавиш`. Mod Menu не требуется.
- Настройки сохраняются в `config/nearby-mob.json`.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---:|---|
| Радиус поиска | 32 блока | От 4 до 128 блоков |
| Отслеживаемые мобы | зомби, скелет, крипер, паук, корова, свинья, овца | Выбираются в поисковом списке |
| Положение и размер HUD | 120×150, 100%/100% | Правый нижний угол; меняются в редакторе |
| Масштаб модели | 48 px | Базовый размер модели |
| Угол HUD | -15° | Вертикальный наклон 3D-модели |
| Скорость вращения | 30°/с | 0 — без вращения |
| Прозрачность фона | 35% | 0 — полностью прозрачная панель |
| Подпись | включена | `Near: <имя моба>` для одного моба; `Имя ×N` для нескольких |
| Расстояние | выключено | Добавляет расстояние в метрах к подписи |
| Рамка | включена | Тонкий контур панели |
| Цвет подписи | белый (ARGB) | Настраивается в Cloth Config |

## Сборка

Требуется JDK 25: Loom 1.18.2 из шаблона требует JVM не ниже 25 (компиляция при этом
идёт с `--release 21`).

```powershell
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-25.0.4.101-hotspot"
.\gradlew build
```

Готовый мод: `build/libs/nearby-mob-1.0.0.jar`.

Для запуска в режиме разработки:

```powershell
.\gradlew runClient
```

## Зависимости

- Fabric Loader 0.19.5+
- Fabric API 0.141.6+1.21.11
- Cloth Config 21.11.160+ (обязательно)
- Mod Menu 17.0.1+ (опционально; для настроек не нужен)

## Структура

```
src/main/java/com/comfortable/nearbymob/
├── NearbyMobClient.java              — entrypoint, регистрация тика и HUD
├── NearbyMobKeybinds.java            — клавиша открытия своего меню настроек
├── config/
│   ├── NearbyMobConfig.java          — загрузка/сохранение JSON
│   ├── NearbyMobConfigScreen.java    — экран Cloth Config
│   ├── MobSelectionScreen.java       — поисковый выбор мобов
│   ├── MobPickerEntry.java           — Cloth-строка выбора мобов
│   ├── HudLayoutEntry.java           — Cloth-строка редактора HUD
│   ├── HudEditorScreen.java          — редактор положения и размера
│   ├── HudLayout.java                — геометрия панели
│   ├── MobCatalog.java               — список доступных мобов и поиск
│   └── ModMenuIntegration.java       — интеграция с Mod Menu
├── tracker/
│   └── MobTracker.java               — поиск мобов и группировка по видам раз в 10 тиков
└── hud/
    ├── NearbyMobHud.java             — живой HUD
    ├── HudRenderer.java              — общий рендерер HUD и редактора
    └── MobPreview.java               — 3D-превью для списка мобов
```
